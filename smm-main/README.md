# Portfolio Desktop

## Run during development

1. Install Node.js (LTS) if it is not already installed.
2. In this folder, run `npm.cmd install` once.
3. Run `npm.cmd run dev` and open the local address shown in the terminal (normally `http://localhost:5173`).

## Build and open with one click

Run `npm.cmd run build` after making changes. Then double-click `Open Portfolio.cmd`.
It starts a small local server and opens the production build in your default browser.

To verify code quality, run `npm.cmd run check`.
